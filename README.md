# YEMAIL / ROSAS website — Phase 1

Static responsive website and illustrative portfolio. The live site is currently manually deployed to Netlify.

## Deploy
Connect this repository to the **existing** Netlify site `yemailrosas1`. Set build command to blank and publish directory to `.` (repository root). `index.html` must remain in the repository root. Do not create a second Netlify site.

## Content editing
This package is a **deployed static snapshot**, not the original content-management source. Portfolio entries are currently embedded in HTML and project pages. Pages CMS and phone-based editing are **not configured yet**. They require a separate content schema and build process; do not assume that adding a CMS configuration alone makes these pages editable.

## Before public launch
Replace illustrative projects with approved actual work, verify business/licensing details, confirm contact address, and test responsive layouts and both hostname orderings. Do not commit private client documents or credentials.
